# Viajes App

Aplicación backend desarrollada con Python y Django para explorar destinos, organizar itinerarios y guardar viajes favoritos.

## Requisitos

- Python 3.x
- Django

## Instalación

1. Clonar el repositorio
2. Crear un ambiente virtual: `python -m venv ambiente`
3. Activar el ambiente virtual:
   - Windows: `ambiente\Scripts\activate`
   - Mac/Linux: `source ambiente/bin/activate`
4. Instalar dependencias: `pip install -r requirements.txt`
5. Ejecutar el servidor: `python manage.py runserver`
6. Abrir en el navegador: `http://127.0.0.1:8000/`
